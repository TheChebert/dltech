# Driftline Tech organic search campaign

## Campaign goal

Make Driftline Tech easy to discover when a decision-maker searches for a website, custom software, automation, AI implementation, technology consulting, or ongoing technical support in the La Crosse, Wisconsin area.

Organic search takes time. The campaign should improve crawlability, relevance, local trust, and conversion without promising a specific position or publishing thin pages written only for search engines.

## Launch checklist

1. Publish the site at the canonical domain and set `NEXT_PUBLIC_SITE_URL=https://driftlinetech.com` in production.
2. Confirm that both the root domain and any `www` version resolve to one canonical HTTPS version.
3. Add the Google Search Console verification token as `GOOGLE_SITE_VERIFICATION` and the Bing verification token as `BING_SITE_VERIFICATION` in the production environment.
4. Create or verify a Google Search Console Domain property for `driftlinetech.com` and submit `https://driftlinetech.com/sitemap.xml`.
5. Inspect and request indexing for the homepage, `/la-crosse-wi`, `/services`, and the six service pages.
6. Import the verified property into Bing Webmaster Tools and confirm that Bing can process the same sitemap.
7. Test the homepage and local landing page with Google's Rich Results Test and Schema.org's validator.
8. Confirm that `robots.txt`, `sitemap.xml`, canonical links, page titles, descriptions, and phone links are available on the production domain.

## Google Business Profile

1. Claim and verify the profile using the exact business name and phone number above.
2. Use the most specific truthful primary category available; add secondary categories only when they describe real services.
3. If Driftline does not receive customers at a staffed location, hide the address and configure the truthful service area.
4. Link the profile to `https://driftlinetech.com/la-crosse-wi` if the profile is primarily local-lead focused; otherwise use the homepage.
5. Add the six service groups using concise descriptions that match the website.
6. Add real brand, team, workspace, and completed-work photos as they become available. Do not use stock images as evidence of local operations.
7. Ask real customers for honest Google reviews after successful work. Never buy, gate, or script reviews. Reply to every review in useful, human language.
8. Publish one helpful profile update each month: a finished project, a practical lesson, a service explanation, or a new resource.

## Authority and local discovery

- Keep the same name, phone, website, and location wording across Google, Bing, Apple Business Connect, LinkedIn, and any legitimate directory profile.
- Pursue local listings and links only where Driftline genuinely participates: chambers, professional groups, partner directories, community sponsorships, vendor directories, and local news coverage.
- Ask project partners and clients for a descriptive website link when a public case study or partner page is appropriate.
- Avoid paid link packages, mass directory submissions, location-page generators, and copied guest posts.

## Helpful content cadence

Publish one substantial, experience-based resource or case study every four to six weeks. Each piece should answer a real buyer question and link to one relevant service page.

Recommended first topics:

1. How to decide between off-the-shelf software and a custom application.
2. A practical website performance and accessibility checklist for small businesses.
3. Where business automation saves time—and where it creates risk.
4. A privacy and human-review checklist for adopting AI in everyday operations.
5. What a maintainable website or application handoff should include.
6. A real Driftline project case study once publication permission and measurable outcomes are available.

Do not invent clients, outcomes, testimonials, project photos, or local expertise. First-hand evidence will outperform generic volume over time.

## Measurement

Review results monthly in Google Search Console and Bing Webmaster Tools.

Track:

- indexed pages and crawl errors;
- impressions and clicks for branded and non-branded searches;
- queries containing La Crosse, Onalaska, Holmen, West Salem, and Coulee Region;
- clicks to the contact page, completed inquiry forms, phone-link clicks, and qualified leads;
- Google Business Profile calls, website visits, messages, and direction requests where applicable;
- new referring domains and genuine customer reviews.

Compare performance in rolling 28-day and 90-day windows. Search changes can take weeks or months, so judge the campaign by qualified visibility and leads rather than day-to-day ranking movement.

## Monthly operating rhythm

- Week 1: review indexing, search queries, leads, and technical alerts.
- Week 2: improve one existing page using actual query and customer-language evidence.
- Week 3: publish or prepare one useful resource, project insight, or case study.
- Week 4: update the Business Profile, request eligible reviews, and pursue one legitimate local or partner mention.

Reassess the page map quarterly. Add new pages only when Driftline has enough distinct expertise, proof, and customer value to make each page genuinely useful.
